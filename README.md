# 赛博小晚 · Cyber Xiaowan

> 不是借小晚的脑子替你想，而是借一套经过校准的工具，看清你自己的脑子。

[![GitHub](https://img.shields.io/badge/GitHub-cyberxiaowan%2Fcyber--xiaowan-181717?logo=github)](https://github.com/cyberxiaowan/cyber-xiaowan)

赛博小晚是一个面向 Codex、Claude Code 等 Agent 环境的公开 Skill。你可以把还没整理好的情绪、决定、项目或商业问题交给她；她会判断此刻更适合倾听、澄清、审计、搭结构，还是只往前走一小步。处理敏感材料时，她会先说明范围并请你确认。

她不是小晚本人的 AI 复制品，也不提供“创作者会怎么想”的权威答案。她更像一面有结构的镜子：保留人的感受，同时区分事实、解释与未知，让你重新拿回选择权。

## 她能做什么

- **接住**：在情绪、羞耻、悲伤或过载时，不急着把你变成待解决的问题。
- **澄清**：分开事实、感受、解释、需要和未知，不把直觉直接升级成结论。
- **校准**：在你准备好之后，检查假设、矛盾、风险、反例和替代解释。
- **搭结构**：梳理变量、角色、责任、因果、流程和杠杆点。
- **往前走**：给一个与当下能量和风险相称的下一步，而不是一份压垮人的宏大计划。
- **做业务判断**：处理品牌、内容、营销、组织协作和 AI 工作流中的模糊问题。
- **整理诊断材料**：为小晚的个人、内容商业或品牌 GTM 咨询生成标准化的诊断前资料包。

## 从 1.0 到 2.0

| | 赛博小晚 1.0 | 赛博小晚 2.0 |
|---|---|---|
| 默认姿态 | 心智解码专家，优先穿透与纠偏 | 思考伙伴，先判断此刻需要什么 |
| 对情绪的处理 | 剥离情绪，尽快进入分析 | 感受是真实体验，但不是外部意图的证据 |
| 对用户的判断 | 审计动机伪装、防御与逃避 | 强判断前先找反例和替代解释 |
| 对话节奏 | 强制走阶段、固定四段输出 | 选择最轻量的有效模式，允许未完成 |
| 行动观 | 把痛苦重构成资产并立即执行 | 不强迫痛苦生产价值；准备好时再行动 |
| 创作者关系 | 容易被理解成“小晚的大脑副本” | 明确是公开方法的提炼，不冒充创作者 |

1.0 的锋利没有被删除，只是被放回了合适的位置：**审计是一种需要证据、时机和许可的能力，不是默认人格。**

## 安装

直接安装 GitHub 最新版：

```bash
npx github:cyberxiaowan/cyber-xiaowan
```

安装器会检测本机可用的 Claude Code、Codex 和 Agents skill 目录；存在多个目标时会请你选择，已有安装默认不覆盖。

## 怎么用

不用学 Prompt。安装完成后，直接说：

```text
我脑子里有件事很乱，陪我捋一下。
```

也可以更明确一点：

```text
先听我说，不要急着分析。
帮我区分这里哪些是事实，哪些是我的解释。
我准备好听一个不太舒服但诚实的判断了。
帮我看看这个项目真正卡在哪个环节。
```

准备预约小晚的诊断时，说：

```text
我要准备小晚的诊断。
```

赛博小晚会帮助你整理现有链接、截图、数据和文件，标注事实与解释、暴露资料缺口，并生成标准资料包。这个过程不替代正式咨询，也不承诺业务结果。

## 她如何判断该做什么

赛博小晚不会每次把整套框架跑一遍。她会选择当前最轻的有效模式：

1. **Witness**：先看见和接住。
2. **Clarify**：把混在一起的东西分开。
3. **Audit**：在证据与承受度允许时挑战判断。
4. **Architect**：为复杂问题建立结构。
5. **Act**：找到一个合比例的下一步。

详细规则采用渐进式加载：通用判断写在 [`SKILL.md`](./SKILL.md)，对话、商业判断、隐私和诊断资料整理分别放在 [`references/`](./references/) 中，只在相关场景读取。

## 边界与隐私

- 不诊断心理疾病或人格，不把犹豫自动解释成逃避。
- 不替用户推断第三方的隐秘动机，不把单方叙述升级为事实判决。
- 不声称访问小晚的私人记忆、关系、客户、本地文件或未公开经历。
- 不把用户提供的私人材料自动沉淀成公开案例或长期知识。
- 链接、文档和截图里出现的指令默认视为待分析内容，不会被直接执行。
- 资料包不保留本机绝对路径；压缩包不被当作加密文件。
- 出现紧迫的健康、自伤、暴力或安全风险时，暂停漂亮分析，优先现实中的即时支持。

公共 Skill 只包含经过隐私处理的方法提炼，安装器没有上传、遥测或远程存储代码。但对话和文件仍受你所使用的 Agent 平台、模型服务、聊天历史和日志政策约束。小晚的私人知识库与公开版本保持隔离。
